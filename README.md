# 부품 AS 전표 관리

공급사 AS 발송·반환 내역 관리, A4 상하 2부 전표 인쇄, 전체 누적 내역 Excel(.xlsx) 다운로드를 지원합니다. 외부 패키지 없이 Python 3.10 이상에서 실행됩니다.

## Windows 실행

1. [Python](https://www.python.org/downloads/) 3.10 이상을 설치합니다.
2. `start-windows.bat`를 더블클릭합니다. 첫 실행에 브라우저가 먼저 열리면 잠시 후 새로고침합니다.
3. 내 업체 설정에서 업체명, 연락처 등을 입력합니다.
4. 새 전표에 공급사와 부품을 입력하고 저장합니다. 반환 시 해당 전표의 수정에서 진행상태, 반환일, 처리 결과를 갱신합니다.
5. 전표 출력 → 프린터로 출력에서 A4, 세로, 배율 100%, 여백 기본(10mm)을 사용하고 브라우저 머리글/바닥글은 해제합니다. 공급자용은 위쪽, 공급받는자용은 아래쪽입니다.
6. 누적 엑셀 다운로드는 필터와 관계없이 저장된 전체 전표의 품목별 행을 내려받습니다. 기존 엑셀 파일을 직접 수정하는 방식이 아니라 데이터베이스에 누적한 뒤 최신 엑셀을 생성합니다.

## 터미널 실행

```sh
cd /workspace/codex
python3 app.py
```

브라우저에서 `http://127.0.0.1:8000`을 엽니다. 종료는 실행창에서 Ctrl+C입니다. `PORT`로 포트, `AS_DATA_DIR`로 데이터 폴더를 변경할 수 있습니다. 기본은 로컬 컴퓨터에서만 접속 가능합니다. 로그인 기능이 없으므로 인터넷에 직접 노출하지 마세요.

## 저장과 백업

모든 전표와 업체 설정은 `data/as.db`에 저장됩니다. 프로그램을 종료한 뒤 `data` 폴더를 별도 디스크에 정기적으로 복사하세요. 엑셀 파일에는 업체 설정 전체가 포함되지 않아 데이터베이스 백업을 대신하지 않습니다. 전표에는 저장 당시 내 업체 정보가 보관되어 이후 업체 설정을 바꿔도 기존 전표는 유지됩니다. 공급자는 AS 처리 공급사, 공급받는자는 내 업체입니다. 접수일과 별개인 반환일을 기록할 수 있습니다.

한 전표에 최대 8개 품목을 기록합니다. 긴 품목/증상은 간결하게 입력하고 출력 미리보기에서 확인하세요. 실제 프린터에 따른 배율 조정은 필요할 수 있습니다. 삭제, 엑셀 가져오기, 사용자별 접근권한 기능은 포함하지 않습니다.
