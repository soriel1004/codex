# 부품 AS 전표 관리

공급사 AS 발송·반환 내역 관리, A4 상하 2부 전표 인쇄, 전체 누적 내역 Excel(.xlsx) 다운로드를 지원합니다. 외부 패키지 없이 Python 3.10 이상에서 실행됩니다.

## Windows 실행

1. [Python](https://www.python.org/downloads/) 3.10 이상을 설치합니다.
2. `start-windows.bat`를 더블클릭합니다. 첫 실행에 브라우저가 먼저 열리면 잠시 후 새로고침합니다.
3. **보낸이 설정**에서 내 업체명·전화번호·담당자를 입력합니다. 주소와 사업자번호는 입력받지 않습니다.
4. **받는이 관리**에서 AS를 처리하는 업체명과 전화번호를 미리 등록합니다. 전표 작성 시 받는이를 선택하면 전화번호가 자동 입력됩니다. 업체명 또는 전화번호로 검색할 수 있으며 전화번호는 하이픈 없이도 찾을 수 있습니다. 등록 정보를 수정해도 기존 전표의 정보는 유지됩니다.
5. **품명 관리**에서 자주 사용하는 품명을 추가합니다. 품명 관리의 검색창으로 등록된 품명을 찾을 수 있습니다. 전표에서는 모델명 구분 없이 품명 하나를 사용합니다. 부품별 **생산 년월**은 월 선택란에서 연도와 월만 입력합니다(일자 없음). 품명 입력란을 눌러 등록 목록에서 선택하거나 직접 입력하고 시리얼번호·수량·불량 증상을 입력합니다. 수기 품명도 해당 전표·엑셀·인쇄에 저장되며, 자주 쓰는 명칭은 품명 관리에서 별도로 등록하세요. 작성 중에도 **품명 추가/관리** 버튼으로 새 명칭을 등록할 수 있습니다. 등록된 품명을 바꿔도 기존 전표의 명칭은 유지됩니다.
6. **전표 작성**에서 받는이와 부품을 입력하고 저장합니다. **출고일**을 선택하면 옆에 해당 월(예: 1월)이 자동 표시됩니다. **택배사**와 **출고 송장번호**를 입력할 수 있으며 송장번호의 앞자리 0이 유지됩니다. 출고일·월·택배사·송장번호는 관리 목록과 엑셀에만 포함되고 전표 인쇄에는 제외됩니다. 출고 정보는 나중에 수정하거나 비워 둘 수 있습니다. 의뢰업체 **GN / 대일**은 선택 사항으로, 둘 다 기본 체크되지 않습니다. 해당 업체가 AS를 의뢰한 건에만 체크하세요. 받는이(AS 처리 업체)와는 별개이며 두 곳을 함께 선택할 수도 있습니다. 목록의 의뢰업체 필터에서 GN·대일·미지정 건을 나눠 볼 수 있습니다. 반환일은 작성 화면에서 입력하지 않습니다.
7. 진행 목록 또는 전체 목록의 **반환** 버튼에서 돌아온 품목을 체크하고 이번 반환 수량·반환일·처리 결과를 입력해 저장합니다. 같은 품목 5개 중 2개만 돌아온 경우에도 2개만 기록할 수 있습니다. 남은 품목과 수량은 계속 진행 목록에서 관리합니다. 교환품의 **입고 시리얼번호**는 품목 오른쪽의 파란 입력 칸에서 입력합니다(좁은 화면에서는 품목 아래에 표시). 시리얼 입력 시 해당 품목이 자동 선택됩니다. 입력하면 원래 **출고 시리얼번호**와 별도로 반환 이력에 보관합니다. 여러 개는 쉼표나 줄바꿈으로 구분하세요. 반환 이력의 **입고 시리얼 저장** 버튼으로 완료 후에도 추가·수정할 수 있으며 출고 시리얼·반환 수량·반환일은 유지됩니다.
8. **전량 반환** 버튼을 누르면 잔여 품목과 수량 전체가 선택된 입력 화면이 열립니다. **입고 시리얼번호**, 반환일, 처리 결과를 확인한 뒤 **전량 반환 저장**을 눌러 반영합니다. 기본 반환일은 오늘이며 바꿀 수 있습니다. 이미 일부가 반환되었다면 잔여 수량만 처리합니다. 입력 중 닫으면 저장되지 않습니다.
9. 전 품목의 전량 반환 시 **완료 목록**으로 자동 이동합니다. 진행·완료·전체 목록을 별도로 볼 수 있으며 완료 전표의 **반환 이력**에서 날짜별 품목·수량·처리 결과를 확인합니다.
10. 전표 출력 → 프린터로 출력에서 A4, 세로, 배율 100%, 여백 기본(프로그램 지정 12mm)을 사용하고 브라우저 머리글/바닥글은 해제합니다. 받는이 보관용은 위쪽, 보낸이 보관용은 아래쪽입니다. 전화번호는 출력되며 주소·사업자번호는 출력되지 않습니다. 접수일은 기존처럼 출력됩니다. 의뢰업체·생산 년월·출고/입고 시리얼도 전표에 포함됩니다.
11. 누적 엑셀 다운로드는 필터와 관계없이 저장된 전체 전표의 품목별 행을 내려받습니다. 기존 엑셀 파일을 직접 수정하는 방식이 아니라 데이터베이스에 누적한 뒤 최신 엑셀을 생성합니다. 반환수량·미반환수량·품목별 날짜/수량/처리 결과 이력, 택배사, 의뢰업체, 생산 년월, 출고·입고 시리얼도 포함됩니다.

## 터미널 실행

```sh
cd /workspace/codex
python3 app.py
```

브라우저에서 `http://127.0.0.1:8000`을 엽니다. 종료는 실행창에서 Ctrl+C입니다. `PORT`로 포트, `AS_DATA_DIR`로 데이터 폴더를 변경할 수 있습니다. 기본은 로컬 컴퓨터에서만 접속 가능합니다. 로그인 기능이 없으므로 인터넷에 직접 노출하지 마세요.

## 저장과 백업

모든 전표와 업체 설정은 `data/as.db`에 저장됩니다. 프로그램을 종료한 뒤 `data` 폴더를 별도 디스크에 정기적으로 복사하세요. 엑셀 파일에는 업체 설정 전체가 포함되지 않아 데이터베이스 백업을 대신하지 않습니다. 전표에는 저장 당시 내 업체 정보가 보관되어 이후 업체 설정을 바꿔도 기존 전표는 유지됩니다. 받는이는 AS 처리 업체, 보낸이는 내 업체입니다. 접수일과 별개인 반환일을 여러 차례 기록할 수 있습니다. 반환 이력이 있는 전표는 품목 추가·삭제·순서·수량 변경을 막아 기존 이력을 보호합니다. 업체 연락처와 비고 등은 수정할 수 있습니다. 반환일은 접수일보다 빠를 수 없고, 미반환 수량을 초과하는 반환이나 중복 요청은 저장되지 않습니다.

한 전표에 최대 8개 품목을 기록합니다. 긴 품명·시리얼·불량 증상은 자동 줄바꿈합니다. 내용이 많으면 각 보관용 전표를 A4 반쪽 안에 들어가도록 자동 축소합니다. 인쇄 미리보기에서 1페이지인지 확인하세요. 프린터 설정도 A4·세로·배율 100%로 맞추고 사용자 지정 확대 배율이나 큰 여백은 해제하세요. 삭제, 엑셀 가져오기, 사용자별 접근권한 기능은 포함하지 않습니다.

## 기존 버전에서 업데이트

프로그램을 종료하고 `data` 폴더를 먼저 백업하세요. 새 ZIP의 프로그램 파일만 기존 폴더에 덮어쓰고 `data` 폴더는 유지한 뒤 다시 실행하세요. 실행 중이던 서버도 종료 후 재시작해야 새 기능이 적용됩니다. 기존 전표의 업체는 받는이 목록으로 이어집니다. 최초 품명 목록을 불러올 때 기존 전표의 품목명과 모델명을 하나의 품명으로 합쳐 자동 등록합니다. 기존 반환 이력도 유지됩니다. 브라우저에서 Ctrl+F5로 화면을 새로고침하세요. 기존 반환완료 전표는 원래 반환일의 전량 반환 이력으로 인식하며 완료 목록에서 확인할 수 있습니다. 데이터 파일을 새로 만들 필요가 없습니다.

자동 테스트는 교환 입고 시리얼과 이력 수정, GN/대일 선택·생산 년월·택배사 저장, 수기 품명 저장·반환·엑셀 보존과 받는이·품명 등록 및 수정, 기존 모델명 통합과 전표 호환, 출고 월 계산·송장번호 보존, 일부 품목/일부 수량 반환, 전량 반환, 반환 이력 보존, 초과·중복·동시 반환 차단, 엑셀 이력 출력을 검증합니다.

## 인쇄 검증 (개발용 선택 사항)

Playwright, Chromium, Poppler(`pdfinfo`, `pdftotext`)가 있는 개발 환경에서는 `node tests/test_print.cjs`로 인쇄 회귀 검증을, `node tests/test_workflow.cjs`로 화면 통합 검증을 실행합니다. 별도 Chromium 실행 파일을 사용하려면 `CHROMIUM_PATH`를 지정합니다. 이 도구들은 일반 프로그램 실행에 필요하지 않습니다.

일반 전표, 긴 내용의 최대 8품목 전표, 좁은 브라우저 창에서 A4 한 페이지·보관용 두 부·마지막 품목과 비고 보존·출력 여백 내 텍스트 배치와 출고일·월·송장번호·주소·사업자번호·모델명 항목의 인쇄 제외를 확인합니다. 화면 통합 검증은 받는이/품명 검색·검색 결과 수정, 품명 선택과 직접 입력, 출고 월 변경, 저장 후 유지, 부분·전량 반환을 포함합니다. 실제 프린터 드라이버의 설정은 출력 화면에서 별도로 확인하세요.
