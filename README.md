# 부품 AS 전표 관리

공급사 AS 발송·반환 내역 관리, A4 상하 2부 전표 인쇄, 전체 누적 내역 Excel(.xlsx) 다운로드를 지원합니다. 외부 패키지 없이 Python 3.10 이상에서 실행됩니다.

## Windows 실행

1. [Python](https://www.python.org/downloads/) 3.10 이상을 설치합니다.
2. `start-windows.bat`를 더블클릭합니다. 첫 실행에 브라우저가 먼저 열리면 잠시 후 새로고침합니다.
3. 내 업체 설정에서 업체명, 연락처 등을 입력합니다.
4. 공급사 관리에서 공급사명·연락처·주소를 미리 등록합니다. 전표 작성 시 공급사를 선택하면 연락처와 주소가 자동 입력됩니다. 등록 정보를 수정해도 기존 전표에 저장된 공급사 정보는 유지됩니다.
5. 새 전표에 공급사와 부품을 입력하고 저장합니다. 반환일은 작성 화면에서 입력하지 않습니다.
6. 진행 목록 또는 전체 목록의 **반환** 버튼에서 돌아온 품목을 체크하고 이번 반환 수량·반환일·처리 결과를 입력해 저장합니다. 같은 품목 5개 중 2개만 돌아온 경우에도 2개만 기록할 수 있습니다. 남은 품목과 수량은 계속 진행 목록에서 관리합니다.
7. **전량 반환** 버튼은 남은 모든 품목과 수량을 **오늘 날짜로 즉시 저장**합니다. 다른 날짜나 처리 결과를 지정하려면 반환 화면에서 **잔여 품목 모두 선택** 후 저장하세요. 이미 일부가 반환되었다면 잔여 수량만 처리합니다.
8. 전 품목의 전량 반환 시 **완료 목록**으로 자동 이동합니다. 진행·완료·전체 목록을 별도로 볼 수 있으며 완료 전표의 **반환 이력**에서 날짜별 품목·수량·처리 결과를 확인합니다.
9. 전표 출력 → 프린터로 출력에서 A4, 세로, 배율 100%, 여백 기본(10mm)을 사용하고 브라우저 머리글/바닥글은 해제합니다. 공급자용은 위쪽, 공급받는자용은 아래쪽입니다.
10. 누적 엑셀 다운로드는 필터와 관계없이 저장된 전체 전표의 품목별 행을 내려받습니다. 기존 엑셀 파일을 직접 수정하는 방식이 아니라 데이터베이스에 누적한 뒤 최신 엑셀을 생성합니다. 반환수량·미반환수량·품목별 날짜/수량/처리 결과 이력도 포함됩니다.

## 터미널 실행

```sh
cd /workspace/codex
python3 app.py
```

브라우저에서 `http://127.0.0.1:8000`을 엽니다. 종료는 실행창에서 Ctrl+C입니다. `PORT`로 포트, `AS_DATA_DIR`로 데이터 폴더를 변경할 수 있습니다. 기본은 로컬 컴퓨터에서만 접속 가능합니다. 로그인 기능이 없으므로 인터넷에 직접 노출하지 마세요.

## 저장과 백업

모든 전표와 업체 설정은 `data/as.db`에 저장됩니다. 프로그램을 종료한 뒤 `data` 폴더를 별도 디스크에 정기적으로 복사하세요. 엑셀 파일에는 업체 설정 전체가 포함되지 않아 데이터베이스 백업을 대신하지 않습니다. 전표에는 저장 당시 내 업체 정보가 보관되어 이후 업체 설정을 바꿔도 기존 전표는 유지됩니다. 공급자는 AS 처리 공급사, 공급받는자는 내 업체입니다. 접수일과 별개인 반환일을 여러 차례 기록할 수 있습니다. 반환 이력이 있는 전표는 품목 추가·삭제·순서·수량 변경을 막아 기존 이력을 보호합니다. 업체 연락처와 비고 등은 수정할 수 있습니다. 반환일은 접수일보다 빠를 수 없고, 미반환 수량을 초과하는 반환이나 중복 요청은 저장되지 않습니다.

한 전표에 최대 8개 품목을 기록합니다. 긴 품목/증상은 간결하게 입력하고 출력 미리보기에서 확인하세요. 실제 프린터에 따른 배율 조정은 필요할 수 있습니다. 삭제, 엑셀 가져오기, 사용자별 접근권한 기능은 포함하지 않습니다.

## 기존 버전에서 업데이트

프로그램을 종료하고 `data` 폴더를 먼저 백업하세요. 새 ZIP의 프로그램 파일만 기존 폴더에 덮어쓰고 `data` 폴더는 유지한 뒤 다시 실행하세요. 실행 중이던 서버도 종료 후 재시작해야 새 기능이 적용됩니다. 기존 전표에 있는 공급사는 최초 공급사 목록 로드 시 자동 등록됩니다. 기존 반환완료 전표는 원래 반환일의 전량 반환 이력으로 인식하며 완료 목록에서 확인할 수 있습니다. 데이터 파일을 새로 만들 필요가 없습니다.

자동 테스트는 공급사 등록·수정, 기존 전표 호환, 일부 품목/일부 수량 반환, 전량 반환, 반환 이력 보존, 초과·중복·동시 반환 차단, 엑셀 이력 출력을 검증합니다.
