등록된 품명관리

품목 반환 처리

돌아온 품목을 선택하고 이번에 반환된 수량과 날짜를 입력하세요. 일부만 반환하면 진행 목록에 남습니다. 시리얼이 바뀐 품목은 시리얼 교체를 체크한 뒤 나타나는 입력칸에 변경된 번호를 입력하세요. 체크하면 해당 품목이 반환 대상으로 선택됩니다. 체크하지 않으면 시리얼 입력칸을 표시하지 않습니다. 완료 버튼은 남은 품목 전체가 선택되어 열리며, 저장 버튼을 눌러야 반영됩니다.

서버 연결 끊김

서버 PC가 종료되었거나 서버와의 연결이 끊겼습니다. 프로그램을 종료하거나, 이 PC에서 재실행해 서버를 이어받을 수 있습니다.

재실행하면 현재 창을 닫고 자동으로 다시 실행합니다. 다른 PC가 먼저 서버가 됐다면 그 서버에 연결합니다. 기존 서버가 네트워크 문제로 응답하지 않는 경우 서버 잠금이 해제될 때까지 전환이 제한될 수 있습니다.

저장하지 않은 입력은 사라집니다. 필요한 내용은 ‘입력 내용 확인’으로 돌아가 복사해 두세요. 저장 중 끊겼다면 재실행 후 목록에서 반영 여부를 먼저 확인하세요.

프로그램 종료

저장하지 않은 입력 내용은 사라집니다. 필요한 내용을 저장한 뒤 종료하세요.

자료 복원

새로 설치한 프로그램에서도 이전에 보관한 AS 백업(.db)을 선택해 이어서 사용할 수 있습니다. 엑셀 파일은 복원용 백업이 아닙니다.

복원하면 현재 자료 전체를 선택한 백업 시점으로 교체합니다. 다른 PC에서 작성·수정 중인 작업을 먼저 마치세요. 복원 직전 자료는 자동으로 별도 백업합니다.
